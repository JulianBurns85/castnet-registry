# Contributing to castnet-registry

## The One Rule

**Never include information that could identify a contributor.**

No GPS coordinates. No node IDs. No IP addresses. No precise timestamps.
Region means city or suburb level only — never street address.

## Evidence Standards

See README.md for minimum evidence requirements.

When in doubt, submit as MEDIUM confidence and let the community review.

## What Makes a Good Submission

- **Reproducible** — observed across multiple sessions, not a one-off
- **Cross-verified** — at least two independent detection signals
- **Documented** — detection method clearly stated
- **Anonymised** — zero contributor fingerprints

## Pull Request Template

Title: `feat: add CID XXXXXXXX — [Carrier] [Country]`

Description:
```
CID: XXXXXXXX
Carrier: 
Country:
Region (city/suburb only):
Detection methods:
Confidence: HIGH / MEDIUM
Hardware profile (if known):
Notes:
```

## Questions

Open an issue. Don't include personal information in issues either.
